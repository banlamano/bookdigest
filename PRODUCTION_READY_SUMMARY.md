## 🚀 Deployment Instructions

### **Quick Start (20 minutes):**

**Step 1: GitHub (5 min)**
```bash
git init
git add .
git commit -m "Production ready"
git remote add origin https://github.com/YOUR-USERNAME/bookdigest.git
git push -u origin main
```

**Step 2: Railway Backend (10 min)**
1. https://railway.app → Deploy from GitHub
2. Add PostgreSQL database
3. Set environment variables
4. Deploy
5. Seed database

**Step 3: Vercel Frontend (5 min)**
1. https://vercel.com → Import from GitHub
2. Set root directory to `frontend`
3. Add backend URL to env vars
4. Deploy

**Done!** 🎉 Your app is live!

See **PRODUCTION_DEPLOYMENT_STEPS.md** for detailed instructions.
