# BookDigest - iOS App

Native iOS application built with SwiftUI and modern iOS development practices.

## 🛠️ Tech Stack

- **Swift 5.9** - Primary programming language
- **SwiftUI** - Modern declarative UI framework
- **Combine** - Reactive programming
- **Alamofire** - Networking
- **Kingfisher** - Image loading & caching
- **AVFoundation** - Audio playback
- **Stripe iOS SDK** - Payment processing
- **KeychainSwift** - Secure storage

## 📋 Prerequisites

- Xcode 15.0+
- iOS 15.0+ deployment target
- macOS Sonoma or later
- Apple Developer Account (for device testing & App Store)
- CocoaPods or Swift Package Manager

## 🚀 Getting Started

### 1. Open in Xcode

```bash
cd ios-app/BookDigest
open BookDigest.xcodeproj
```

### 2. Install Dependencies

Using Swift Package Manager (recommended):
- File → Add Packages
- Add URLs for dependencies

### 3. Configure

Update `Config.swift` with your API endpoints and keys.

### 4. Build & Run

Select a simulator or device and press Cmd+R

**Build Errors**: Clean build folder (Cmd+Shift+K)
**Simulator Issues**: Reset simulator
**Signing**: Configure team in project settings
