## 📋 HOW TO USE

### **Step 1: Login**

1. Go to: https://bookdigest.vercel.app/login
2. Login with your account
3. Navigate to: https://bookdigest.vercel.app/admin/covers

### **Step 2: Find Books Needing Covers**

1. Click the **"Broken"** filter button
2. You'll see all books with missing/broken covers (red dot)
3. Use search if needed to find specific book

### **Step 3: Update a Cover**

1. **Click on a book** from the list
2. **Find the cover image:**
   - Google: Search "book title book cover"
   - Go to Amazon and right-click on cover
   - Select "Copy Image Address"
3. **Paste the URL** in the "New Cover URL" field
4. **Preview** - You'll see the cover preview below
5. **Click "Update Cover"**
6. ✅ Done! The book is updated

### **Step 4: Repeat**

- Book automatically moves from "Broken" to "Good"
- Select next book from list
- Continue until done!

## 🖼️ WHERE TO FIND COVER IMAGES

### **Method 1: Amazon (BEST)**

1. Search for book on Amazon
2. Find the book cover image
3. Right-click → "Copy Image Address"
4. Paste in admin panel

**Example URL:**
```
https://m.media-amazon.com/images/I/81abc123xyz.jpg
```

### **Method 2: Google Images**

1. Google: "book title book cover"
2. Find high-quality image
3. Right-click → "Copy Image Address"
4. Paste in admin panel

### **Method 3: Goodreads**

1. Search book on Goodreads
2. Right-click cover image
3. "Copy Image Address"
4. Paste in admin panel

### **Method 4: Upload to ImgBB**

1. Download cover image to your computer
2. Go to https://imgbb.com
3. Upload the image
4. Copy "Direct Link"
5. Paste in admin panel

## ❓ TROUBLESHOOTING

### **Problem: "Cover URL required" error**
**Solution:** Make sure you pasted a URL starting with `http://` or `https://`

### **Problem: Image doesn't load in preview**
**Solution:** The URL might be blocked. Try a different source (Amazon, Goodreads)

### **Problem: Update button doesn't work**
**Solution:** Check browser console for errors. Ensure you're logged in.

### **Problem: Can't access /admin/covers**
**Solution:** Make sure you're logged in first. Go to /login
