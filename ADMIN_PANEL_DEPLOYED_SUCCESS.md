## 🚀 HOW TO USE IT

### **Step 1: Access the Admin Panel**

1. Go to: https://bookdigest.vercel.app/login
2. Login with your account
3. Navigate to: https://bookdigest.vercel.app/admin/covers

### **Step 2: Update a Cover (Simple 5-Step Process)**

1. **Click "Broken" filter** → See all books needing covers
2. **Click on a book** → Select it
3. **Find cover on Amazon/Google** → Right-click, copy image URL
4. **Paste URL** in the admin panel → See live preview
5. **Click "Update Cover"** → Done! ✅

### **Example Workflow:**

```
1. Click "Broken" filter
2. Select "The Kite Runner"
3. Google: "The Kite Runner book cover"
4. Copy image URL: https://m.media-amazon.com/images/I/81abc.jpg
5. Paste in admin panel
6. Click "Update Cover"
7. ✅ Book moved to "Good" status
```

**Time per book:** 30-60 seconds  
**Books per hour:** 30-60 covers  
**Total time for 364 books:** 6-12 hours (spread over days/weeks)

## 🖼️ WHERE TO GET COVER IMAGES

### **Best Sources:**

1. **Amazon** (highest quality)
   - Search book on Amazon
   - Right-click cover → "Copy Image Address"
   
2. **Google Images**
   - Search: "book title book cover"
   - Right-click → "Copy Image Address"

3. **Goodreads**
   - Find book page
   - Right-click cover → "Copy Image Address"

4. **ImgBB** (if you have local images)
   - Upload to https://imgbb.com
   - Copy "Direct Link"
